# Zadatak 1: Prijedlozi za poboljšanje implementacije eventa

## 1. Dodati evente za detaljnije korištenje funkcionalnosti

**Što:**  
Dodati evente koji prate koje dijelove utakmice korisnici zapravo pregledavaju:
- `view_statistics`
- `view_lineups`
- `view_h2h`
- `view_standings`

**Kako:**  
Event se šalje kada korisnik otvori odgovarajući tab unutar stranice utakmice.

Primjer propertyja:
- `event_id`
- `tab_name`
- `match_status`

**Zašto:**  
Trenutno se prati samo `open_event`, ali ne i što korisnici rade unutar stranice utakmice.  
Ovo bi omogućilo razumijevanje koji sadržaj korisnici najviše koriste i koje funkcionalnosti povećavaju engagement.

---

## 2. Dodati event za pretragu

**Što:**  
Pratiti kada korisnici pretražuju timove, igrače ili lige.

Event:
- `search`

Propertyji:
- `query`
- `result_type` (team / player / league)
- `result_id`

**Kako:**  
Event se šalje kada korisnik napravi pretragu i klikne na rezultat.

**Zašto:**  
Pretraga otkriva namjeru korisnika i pomaže identificirati popularne timove, igrače i natjecanja.

---

## 3. Dodati evente za interakciju s notifikacijama

**Što:**  
Pratiti interakcije s push notifikacijama.

Eventi:
- `notification_open`
- `notification_click`
- `notification_dismiss`

Propertyji:
- `notification_type`
- `event_id`
- `team_id`

**Zašto:**  
Ovo pomaže mjeriti koliko su notifikacije učinkovite u vraćanju korisnika u aplikaciju.

---

## 4. Poboljšati kontekst postojećih eventa

**Što:**  
Dodati dodatne propertyje postojećim eventima poput `open_event`.

Primjeri propertyja:
- `source` (search / favorites / notification / home_feed)
- `device_platform`
- `user_region`

**Zašto:**  
Time se može bolje razumjeti put kojim korisnici dolaze do određenog sadržaja i kako otkrivaju funkcionalnosti aplikacije.

---

## 5. Event koji bih deprecirao

**Event:**  
`live_button`

**Zašto:**  
Ovaj event prati samo klik na UI element i daje ograničenu analitičku vrijednost.

**Poboljšanje:**  
Zamijeniti ga smislenijim eventom poput:

`view_live_matches`

Propertyji:
- `match_count`
- `league_id`
- `source`

Ovaj event bi bolje opisivao stvarnu namjeru korisnika – pregled live utakmica.

---

## Zaključak

Dodavanjem eventa vezanih uz korištenje funkcionalnosti, pretragu i notifikacije može se bolje razumjeti angažman korisnika i korištenje pojedinih dijelova aplikacije.  
Istovremeno, uklanjanje eventa koji prate samo UI klikove može poboljšati kvalitetu i jasnoću analitičkih podataka.
